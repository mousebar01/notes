# VideoAgent

这里记录视频智能体项目的范围判断、已核验能力、当前设计和候选方向。文档区分“原项目宣称”“代码线索”“实际跑通”和“当前采用”，避免把论文或旧 Demo 的叙事直接当成现状。

> 当前判断（2026-07-13）：暂定主线是先完成一个可运行的 `storyboard -> retrieval -> trim -> 拼接` 闭环，不继续追求通用动态多 Agent 视频生产系统。这个判断来自现有工程落地复盘，仍待作者最终确认。

## 两条候选方向

### 方向 A：动态多 Agent 视频编辑 / 创作

上游项目希望根据用户意图动态规划 Agent DAG，覆盖视频理解、编辑、创作、音频处理和创意改编。现有笔记能找到注册表、意图表和部分角色实现的线索，但没有足够证据证明 19 类意图和完整端到端链路都已跑通。

当前只采用其中最小、可验收的子集：需求转 storyboard、按场景检索素材、裁剪候选片段、顺序拼接成片。配音、字幕、BGM 和基础转场可以在主链稳定后逐项加入。

### 方向 B：长视频理解 / 问答

另一条方向是字幕优先、ASR 补全、视觉兜底的长视频理解系统，输出带时间戳证据的摘要与问答。它有独立的 MVP 和功能 Backlog，目前仍是候选方向，不代表已经进入实现。

## 当前决策

- **暂定主线**：`storyboard -> retrieval -> trim -> 拼接`。
- **暂不采用**：通用动态 DAG 优化、任意视频编辑 Agent、换脸、lip-sync、多情绪语音克隆及复杂创意改编。
- **候选支线**：长视频理解与问答 MVP。
- **待确认**：作者是否正式选择暂定主线，以及现有代码中哪些链路已在当前环境重复跑通。
