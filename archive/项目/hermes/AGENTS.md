# Hermes Project Rules

这里记录 Hermes、Kanban、多 Agent、worker 和 ACP 等项目内容。

- `kanban/` 是自己的中文整理笔记；原 `concepts/` 已合并到协作文档，原稿放在 `archive/projects/hermes/concepts/`。
- heartbeat、TTL、lease 等通用工程知识放 `topics/software-engineering/`，项目内只保留 Hermes 特有映射。
- `reference/` 尽量保留原始资料，不大幅改写。
- 新增总结时优先更新 `README.md` 的阅读路线。
- 每篇区分源码验证、设计稿、个人推断和待确认；Design Only 不写成已实现。
