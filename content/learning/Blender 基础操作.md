# Blender 基础操作总结

下面是刚刚学到的 Blender 入门内容总结，方便以后查找快捷键和基础建模步骤。

## 一、视图操作

这些是用来调整你“看模型的角度”，不会改变模型本身。

| 功能        | 快捷键                 |
| --------- | ------------------- |
| 旋转视图      | 按住 **鼠标中键** 拖动      |
| 平移视图 / 抓手 | **Shift + 鼠标中键** 拖动 |
| 放大缩小视图    | 滚动 **鼠标滚轮**         |
| 进入相机视图    | **0**               |
| 聚焦选中物体    | 小键盘 **.**           |
| 显示全部物体    | **Home**            |
| 独显选中物体    | **/**               |

## 二、常用视角快捷键

一般使用小键盘数字键。

| 快捷键          | 作用          |
| ------------ | ----------- |
| **1**        | 正视图         |
| **3**        | 侧视图         |
| **7**        | 顶视图         |
| **5**        | 透视 / 正交视图切换 |
| **Ctrl + 1** | 后视图         |
| **Ctrl + 3** | 另一侧视图       |
| **Ctrl + 7** | 底视图         |

## 三、物体变换快捷键

这些会真正改变物体的位置、角度和大小。

| 功能 | 快捷键   |
| -- | ----- |
| 移动 | **G** |
| 旋转 | **R** |
| 缩放 | **S** |

缩放时可以限制方向：

| 操作        | 作用       |
| --------- | -------- |
| **S**     | 整体缩放     |
| **S + X** | 只沿 X 轴缩放 |
| **S + Y** | 只沿 Y 轴缩放 |
| **S + Z** | 只沿 Z 轴缩放 |

例子：

| 操作                    | 效果    |
| --------------------- | ----- |
| **S → Z → 0.25 → 回车** | 把物体压扁 |
| **S → X → 2 → 回车**    | 让物体变宽 |
| **S → Y → 1.5 → 回车**  | 让物体变长 |

## 四、Blender 两种常用模式

### 1. 物体模式 Object Mode

用来操作**整个物体**。

适合做：

| 操作     | 说明                         |
| ------ | -------------------------- |
| 移动整个物体 | 调位置                        |
| 旋转整个物体 | 调方向                        |
| 缩放整个物体 | 调整体大小                      |
| 删除物体   | 删除整个模型                     |
| 添加修改器  | 比如 Bevel 倒角、Subdivision 细分 |
| 加材质    | 给模型设置颜色                    |

简单记：
**物体模式 = 管整个模型。**

### 2. 编辑模式 Edit Mode

用来编辑物体内部的结构，也就是**点、边、面**。

适合做：

| 操作  | 快捷键          |
| --- | ------------ |
| 点选择 | **1**        |
| 边选择 | **2**        |
| 面选择 | **3**        |
| 全选  | **A**        |
| 挤出  | **E**        |
| 内插面 | **I**        |
| 倒角  | **Ctrl + B** |
| 环切  | **Ctrl + R** |
| 切割  | **K**        |

简单记：
**编辑模式 = 改点、边、面。**

切换模式：

**Tab**

## 五、坐垫制作流程

用默认立方体做坐垫：

1. 选中立方体
2. 按 **S → X → 2**，变宽
3. 按 **S → Y → 1.5**，变长
4. 按 **S → Z → 0.25**，压扁
5. 按 **Tab** 进入编辑模式
6. 按 **A** 全选
7. 按 **Ctrl + B** 倒角
8. 移动鼠标调整圆角大小
9. 滚动鼠标滚轮增加圆角分段
10. 左键确认
11. 右键模型，选择 **Shade Smooth / 平滑着色**

推荐倒角参数：

| 参数              | 建议        |
| --------------- | --------- |
| Amount / Radius | 0.1 ~ 0.2 |
| Segments        | 5 ~ 8     |

## 六、倒角 Bevel

倒角就是让模型的边角变圆。

两种方法：

### 方法一：快捷键

1. 进入编辑模式：**Tab**
2. 全选：**A**
3. 倒角：**Ctrl + B**
4. 移动鼠标调大小
5. 滚轮调分段
6. 左键确认

### 方法二：修改器

在物体模式下：

**右侧扳手图标 → Add Modifier → Bevel**

常用参数：

| 参数              | 作用   |
| --------------- | ---- |
| Amount / Radius | 倒角大小 |
| Segments        | 圆滑程度 |

修改器方式更适合新手，因为后面还能继续调。

## 七、变回正方体

如果只是想重新得到一个干净的正方体，最快方法：

1. 选中当前物体
2. 按 **X** 删除
3. 按 **Shift + A**
4. 选择 **Mesh / 网格 → Cube / 立方体**

如果只是想把长条缩短：

**S → Y → 缩小**

比如：

**S → Y → 0.25 → 回车**

## 八、左侧工具栏常用图标

| 工具    | 作用         |
| ----- | ---------- |
| 选择工具  | 选择物体、点、边、面 |
| 3D 游标 | 设置新物体生成位置  |
| 移动    | 拖动物体或点边面   |
| 旋转    | 旋转         |
| 缩放    | 改大小        |
| 变换    | 移动、旋转、缩放合一 |
| 注释    | 在视图里画标记    |
| 测量    | 测距离和角度     |
| 挤出    | 拉出新形状      |
| 内插面   | 在面里面缩出一圈   |
| 倒角    | 让边角变圆      |
| 环切    | 给模型增加一圈线   |
| 刀具    | 手动切割模型     |

新手最常用的是：

**移动、旋转、缩放、挤出、内插面、倒角、环切。**

## 九、Blender 中文界面

Blender 自带中文，不需要专门汉化插件。

设置路径：

**Edit → Preferences → Interface → Translation**

建议：

| 选项        | 设置                        |
| --------- | ------------------------- |
| Language  | Simplified Chinese / 简体中文 |
| Interface | 勾选                        |
| Tooltips  | 勾选                        |
| New Data  | 不建议勾选                     |

原因是：
物体、材质名字保持英文，跟教程更方便。

## 十、插件建议

新手不建议一开始装太多插件。

可以以后再了解这些：

| 插件                      | 作用         |
| ----------------------- | ---------- |
| Node Wrangler           | 材质节点更方便    |
| LoopTools               | 修圆、桥接、平整边线 |
| Bool Tool               | 布尔切割更方便    |
| Add Mesh: Extra Objects | 增加更多基础模型   |

当前阶段重点掌握：

**S 缩放、G 移动、R 旋转、Ctrl+B 倒角、Ctrl+R 环切、E 挤出、Tab 切模式。**
