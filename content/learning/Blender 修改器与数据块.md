# Blender 修改器与数据块

这篇笔记整理两个容易混淆的 Blender 心智模型：修改器结果与真实网格的区别，以及多个 Object 共享同一 Mesh 数据时的“用户”含义。

## 修改器与真实网格

这个问题非常关键。理解“**应用修改器（Apply Modifier）**”以后，你对 Blender 的很多东西会突然开窍。

简单说：

> **修改器默认只是一个“实时计算的效果层”，应用就是把这个效果永久写进模型本身。**

---

举个你现在的细分例子。

你有一个球：

### 原始网格（真实存在的东西）

可能只有：

```
    ◯
  32个面
```

然后你加了：

**细分曲面 Subdivision Surface**

屏幕上看到：

```
    ⚪
  几千个面
```

但是实际上：

你的模型内部还是：

```
低模球
+
一个“变圆滤镜”
```

修改器只是告诉 Blender：

> “显示的时候，把它变圆一点。”

---

## 不应用时

结构：

```
模型
 |
 |-- 原始网格（低模）
 |
 |-- 细分修改器
```

优点：

✅ 随时可以改
✅ 可以调细分等级
✅ 文件更轻
✅ 建模更灵活

缺点：

❌ 后面的某些操作看不到真实效果

比如你遇到的：

```
细分（显示圆）
        ↓
Voxel Remesh
        ↓
读取低模
        ↓
变方
```

---

## 应用之后

结构变成：

```
模型
 |
 |-- 高模网格（已经细分）
```

也就是说：

原来的：

```
低模 + 计算
```

变成：

```
真正的高模
```

之后：

* 雕刻
* 体素重构
* 编辑顶点

都会基于这个真实形状。

---

## 用现实比喻

修改器像：

> 给模型套一个“智能滤镜”。

比如手机美颜：

照片：

```
原脸
+
美颜算法
```

看起来漂亮。

应用：

```
把美颜效果直接烙进照片
```

以后照片本身就是那个样子。

---

## Blender 常见修改器：

### 1. 细分曲面

不应用：

```
低模
+
变圆算法
```

应用：

```
真正高模
```

---

### 2. 镜像

不应用：

```
左半边
+
镜像计算
```

应用：

```
左右两半真正存在
```

你刚才分离眼睛就是这个。

---

### 3. 阵列

不应用：

```
一个零件
+
复制规则
```

应用：

```
真的有100个零件
```

---

## 什么时候应用？

一般：

### 建模阶段：

不要急着应用。

例如：

你做身体：

```
低模
+
细分
```

很好调。

---

### 准备雕刻/导出：

考虑应用。

例如：

你现在：

```
触角
+
细分
↓
Voxel Remesh
```

这时候应该应用。

---

## 一个非常实用的判断：

问自己：

> “我之后还需要调整这个修改器吗？”

如果：

### 需要

不要应用。

比如：

* 还要调整细分等级
* 还要改镜像方向

---

### 不需要

可以应用。

比如：

* 我要雕刻
* 我要 Remesh
* 我要导出游戏模型

---

你现在做水蓝蓝，其实正好碰到了 Blender 的核心思想：

**对象（Object） ≠ 网格（Mesh） ≠ 修改器结果（Modifier Result）**

新手最容易混淆的就是这三个。

你之前遇到“为什么我看到是圆的，Remesh却变方了”，本质就是：

> 你看到的是修改器后的模型，但 Remesh 用的是修改器之前的真实网格。

搞懂这个，后面 Blender 会顺很多。🙂


## 数据块与单用户化

“单用户化”里的“用户”不是指人，而是指：

> **有多少个对象正在引用同一个数据块。**

## 先看 `Alt + D`

执行：

```text
Alt + D
```

得到：

```text
Object A ─┐
          ├── Mesh 数据
Object B ─┘
```

同一个 Mesh 被两个 Object 使用，所以：

```text
Mesh.users = 2
```

这就是“多用户数据”。

## 单用户化做什么？

假设你只选中 B，执行：

```text
物体 > 关系 > 使单用户化 > 对象和数据
```

Blender 会复制一份 Mesh，并让 B 改用这份新数据：

```text
Object A -> Mesh A
Object B -> Mesh B
```

结果：

```text
Mesh A.users = 1
Mesh B.users = 1
```

这就是“单用户化”。

它不是删除对象，而是：

```text
复制共享数据
让当前对象拥有自己的数据副本
```

## 为什么需要它？

单用户化之前：

```text
编辑 B 的顶点
  -> Mesh 数据改变
  -> A 和 B 一起改变
```

单用户化之后：

```text
编辑 B 的顶点
  -> 只修改 Mesh B
  -> A 不受影响
```

对象的位置、旋转、缩放本来就已经独立；单用户化主要解决的是**几何数据共享**。

## 可以用 Python 观察

```python
obj = bpy.context.active_object
obj.data.users
```

如果结果是：

```python
2
```

表示有两个对象共享这个 Mesh。

单用户化后通常会变成：

```python
1
```

用代码表达就是：

```python
obj.data = obj.data.copy()
```

这会为当前对象复制一份独立的 Mesh 数据。

所以最重要的关系是：

```text
Object = 谁在使用数据
Mesh   = 被使用的数据
users  = 有多少个 Object 在使用它
单用户化 = 给当前 Object 复制一份独立数据
```
