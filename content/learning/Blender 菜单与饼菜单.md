# Blender 菜单与饼菜单

这篇笔记从饼菜单出发，整理 Blender 中常见的菜单类型、快捷入口及其与 Operator 的关系。

**饼菜单（Pie Menu）**是一种把选项围绕鼠标指针排列成圆形的菜单。

你刚才看到的就是一个饼菜单：

```text
边界框中心   质心点   活动元素
各自原点     轴心点   3D 游标
              仅位置
```

每个选项像一块“饼”，所以叫 Pie Menu。

## 它和普通菜单的区别

普通菜单：

```text
选项一
选项二
选项三
选项四
```

饼菜单：

```text
        上
左                右
        下
```

优点是：

- 鼠标移动距离短；
- 方向固定，熟悉后很快；
- 可以使用数字或方向快捷键；
- 菜单出现在鼠标附近，不需要移动到顶部菜单栏。

你截图中的数字就是快捷键：

```text
7  活动元素
8  质心点
4  边界框中心
2  各自的原点
6  3D 游标
9  仅位置
```

## Blender 中的常见饼菜单

```text
.       Pivot Point 轴心点菜单
Shift+S Snap 吸附菜单
Z       着色模式菜单
```

例如：

```text
按 Z
```

会出现线框、实体、材质预览、渲染等显示选项。

饼菜单的设计目标是：

```text
常用选项集中到一个快捷键
通过方向或数字快速选择
```

它适合熟练操作，但对新用户不太明显，因为用户必须先知道哪个快捷键会打开哪个饼菜单。

Blender 中常见的菜单和菜单式界面大致有这些。

| 类型 | 形态 | 常见入口 | 作用 |
|---|---|---|---|
| 主菜单 | 顶部横向菜单 | `文件`、`编辑`、`物体` | 按功能分类组织命令 |
| 子菜单 | 菜单中的下一层 | `物体 > 变换` | 继续细分功能 |
| 上下文菜单 | 根据当前位置和状态变化 | 右键 | 提供当前对象可用的操作 |
| 饼菜单 | 选项围绕中心排列 | `.`、`Shift+S`、`Z` | 快速选择常用命令 |
| 下拉菜单 | 点击按钮或箭头展开 | 吸附设置、坐标系选择 | 选择一个模式或选项 |
| 弹出面板 | 浮动的小型设置面板 | 磁铁下拉箭头、Overlays | 调整多个相关参数 |
| 搜索菜单 | 搜索框加命令列表 | `F3` | 不知道菜单位置时查找功能 |
| 操作调整面板 | 显示刚执行操作的参数 | `F9` | 修改上一步 Operator 的参数 |
| 选择器菜单 | 列出对象、材质、集合等 | 数据块选择按钮 | 从已有数据中选择目标 |
| 模式菜单 | 选择工作模式 | `Tab`、左上角模式选择 | Object/Edit/Pose 等模式切换 |
| 右键上下文面板 | 当前项的专用命令 | 在属性、节点、时间轴中右键 | 根据编辑器和目标动态变化 |

## 几个容易混淆的类型

### 下拉菜单

例如点击：

```text
全局
```

展开：

```text
全局
局部
法向
视图
游标
```

它通常选择一个值。

### 弹出面板

例如点击吸附图标旁边的小箭头，会出现：

```text
吸附目标
吸附方式
影响对象
投影
```

它不是单纯选择一个命令，而是集中调整设置。

### 饼菜单

例如：

```text
.
```

打开 Pivot Point 菜单；

```text
Shift + S
```

打开 Snap 菜单；

```text
Z
```

打开视图着色菜单。

### 搜索菜单

```text
F3
```

搜索的是已经注册的 Operator。它相当于 Blender 的全局功能索引。

## 从源码看

Blender 的菜单界面主要在：

```text
scripts/startup/bl_ui/
```

例如 3D Viewport：

```text
scripts/startup/bl_ui/space_view3d.py
```

饼菜单通常使用：

```python
layout.menu_pie()
```

普通菜单通常使用：

```python
class SomeMenu(Menu):
```

实际功能则经常调用：

```python
layout.operator(...)
```

所以可以把 Blender 的界面理解为：

```text
菜单类型：负责如何呈现
菜单项目：负责显示什么
Operator：负责实际执行什么
```

例如：

```text
Shift + S
  -> 饼菜单
  -> Selection to Cursor
  -> VIEW3D_OT_snap_selected_to_cursor
  -> 修改对象变换数据
```
