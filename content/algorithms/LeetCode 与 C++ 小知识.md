# LeetCode 与 C++ 小知识

这篇用来收拢刷题过程中遇到的零散概念，先保证以后能找回。内容目前主要包括字典序、异或逻辑和 `unordered_map` 遍历。

## 字典序

**字典序**就是像查字典一样比较大小。

对于数字数组来说，可以理解成：

> 从左到右，一个位置一个位置比较，谁先出现较大的数字，谁就更大。

例如：

```text
[1,2,3]
[1,3,2]
```

第一位都是 `1`，继续比较第二位：

```text
2 < 3
```

所以：

```text
[1,2,3] < [1,3,2]
```

再例如：

```text
[1,9,9]
[2,0,0]
```

虽然后面的数字很大，但第一位已经决定了大小：

```text
1 < 2
```

所以：

```text
199 < 200
```

这和查字典时比较单词的方法一样。比如 `apple` 和 `apply`，前四个字母相同，第五个字母 `e < y`，所以 `apple < apply`。

### LeetCode 31：下一个排列

所有排列按照字典序排列，例如：

```text
123
132
213
231
312
321
```

所以：

```text
123 的下一个排列是 132
132 的下一个排列是 213
231 的下一个排列是 312
```

如果已经是最大排列：

```text
321
```

就重新回到最小排列：

```text
123
```

## 异或逻辑

异或常用于处理“其他数字都出现两次，只有一个数字出现一次”的题目。

关键性质：

```text
a ^ 0 = a
a ^ a = 0
```

因此初始值设为 `0` 时，不会改变第一次异或的数字本身；两个相同数字异或后会抵消为 `0`。

例如：

```text
2 ^ 3 ^ 2
= (2 ^ 2) ^ 3
= 0 ^ 3
= 3
```

补充：

```text
同或（XNOR） = 异或（XOR）再取反（NOT）
```

## unordered_map 遍历

`unordered_map` 没有稳定顺序，每次遍历顺序都可能不同。刷题时如果只关心 key / value，不要依赖输出顺序。

### 范围 for

```cpp
for (auto x : mymap) {
    cout << x.first << " " << x.second << endl;
}
```

这里：

```cpp
x.first   // key
x.second  // value
```

题目中常见写法：

```cpp
for (auto x : mymap) {
    if (x.second > n / 2) {
        return x.first;
    }
}
```

### 引用遍历

```cpp
for (auto& x : mymap) {
    cout << x.first << " " << x.second << endl;
}
```

`auto&` 表示引用，不会复制整个 `pair`，实际写代码时更常用。

### 迭代器遍历

```cpp
for (auto it = mymap.begin(); it != mymap.end(); it++) {
    cout << it->first << " ";
    cout << it->second << endl;
}
```

这里：

```cpp
it->first
```

等价于：

```cpp
(*it).first
```

因为 `it` 是迭代器，可以近似理解成一种指向元素的对象。
