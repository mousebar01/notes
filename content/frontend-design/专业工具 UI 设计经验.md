# 专业工具 UI 设计经验

这篇笔记记录一次专业创作工具界面调整中形成的判断，重点是工作区的归属关系、布局网格、信息密度和视觉层级。

## AI 生成 UI 的常见倾向

> 很容易会去写一些解释性文本，然后缺少一定的审美

这类问题通常表现为解释性文案过多、装饰代替层级，以及界面更像展示页面而不是可持续使用的工作区。下面的记录是对这些问题的一次具体修正。

## 调整背景

这就是专业工具里常见的“标签与内容共面”。
已经调整：
选中标签与展开面板使用完全相同的背景色。
取消选中标签的圆角、阴影和蓝色侧条。
标签铺满侧轨宽度，与内容直接连接。
未选中标签保留在更深的轨道背景上。
规划和 3D 工作区、浅色和深色模式已统一。

**核心原则**

> 专业工具的美感主要来自明确的归属、稳定的网格和连续的表面，而不是更多装饰、阴影或深色主题。

| 技巧 | 具体规则 |
| --- | --- |
| 单一交互模型 | 不同时保留节点画布和任务工作台两套主流程 |
| 明确控件层级 | 区分项目、阶段、区域、对象、工具五个作用范围 |
| 控件靠近对象 | 镜头选择、生成、变换、聚焦应位于对应编辑器附近 |
| 顶栏保持克制 | 只放项目身份、`规划 / 镜头 / 成片`和保存状态 |
| 删除重复标题 | 同一个当前位置不要在顶栏、工具栏、正文连续出现 |
| 工具栏按需出现 | 不为了三个阶段形式一致而保留空的共享说明栏 |
| 一条命令一个主入口 | 避免同一功能在顶栏、面板和正文重复出现 |
| 侧栏按需展开 | 默认只打开当前最需要的一侧，另一侧通过标签恢复 |
| 紧凑宽度面板互斥 | 约1184px以下打开一侧时自动关闭另一侧 |
| 聚焦不破坏状态 | 聚焦只临时隐藏面板，退出后恢复之前的宽度和开合状态 |

**标签设计**

- 选中的标签与展开面板使用完全相同的背景色。
- 活动标签应该像面板表面的延伸，而不是悬浮按钮。
- 活动状态取消卡片阴影、过大圆角和多余分隔线。
- 未选中标签留在更深一层的轨道背景上。
- 只有一个功能时，不要制造一整列空标签或空轨道。
- 标签负责切换内容，按钮负责执行命令，不要混淆。

**布局技巧**

- 先建立贯穿上下的列网格，再放具体内容。
- 左侧负责找对象，中央负责直接创作，右侧负责当前对象属性，底部负责时间关系。
- 底部摘要、时间轨和主操作要分别对齐左侧、中央和右侧区域。
- 不要让底部状态条独立横跨所有区域，破坏上方列边界。
- 稀疏属性面板不要随着宽屏无限变宽，应把新增空间交给中央编辑器。
- 当前规划区适合约 `248px` 左侧对象面板、`304px` 右侧属性面板，右侧上限约 `360px`。
- 工具栏高度统一在 `36-40px`，图标按钮通常保持 `28px`。
- 面板和工具表面使用较小圆角，避免网页卡片感。

**内容布局**

- 中央编辑器不能只是一个悬浮在大白底上的窄网页文档。
- 宽屏时适当扩大中央内容宽度，但控制文本行长。
- 视频镜头需要稳定的16:9画面位、镜头号、时长和状态。
- 没有真实预演时显示诚实的“待预演”状态，不伪造缩略图。
- 信息密度要均衡，避免顶部很挤、中央和右侧大片空白。
- 空白本身没有问题，但必须表现为工作画布，而不是未完成的网页。

**视觉层级**

- 使用稳定的表面层级区分项目栏、工具栏、面板、中央画布和输入控件。
- 选中、悬停、禁用和执行中状态要有明确但克制的差异。
- 文字建议控制在少量固定层级，例如 `10px / 11px / 12px / 14px`。
- 小字号必须保证对比度，避免大量低对比灰字。
- 状态颜色用于传达语义，不作为装饰。
- resize handle、活动边和焦点状态要能被发现。

**区域工具栏**

当前规划区不需要继续增加层级，应该精简为：

```text
左侧：脚本段  12 · 60s
中央：          文稿 | 镜头拆分                 聚焦
右侧：脚本段属性 / 镜头属性
```

中央工具栏不再重复当前脚本段标题；右侧避免“规划操作”这种模糊名称。整体方向是：**减少描述当前位置的文字，保留真正可以操作的控件。**
